# Cal-On EV Web

A modern and responsive web application focused on electric vehicle solutions. Cal-On EV provides users with information about electric mobility, EV products, and sustainable transportation.

## 🚀 Features

- Modern and responsive user interface
- Electric vehicle-focused design
- Clean and user-friendly navigation
- Custom SVG icons and visual assets
- Responsive website layout
- Built with React and Vite

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- npm

## 💻 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/nagapavan39/cal-on-ev.git
```

### 2. Navigate to the project folder

```bash
cd cal-on-ev
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 📦 Build for Production

```bash
npm run build
```
